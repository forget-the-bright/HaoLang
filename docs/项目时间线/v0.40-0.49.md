### v0.43.0（2026-08-08）· 审计修复计划 B（regex/HTTP/CHM/GC）

> **目标**：修完已复现中等问题 + 审计表 runtime/stdlib 缺口；HTTP chunked + 可配置读上限；不将就。不做 TLS / 自举 / 包管理第 2 层 / 增量编译 F。

- **regex**：捕获迁到 Matcher 侧 `[Int]`；多 Matcher 不串写；整次 `search` 共用步数预算；同盒 `compile` 禁 remake（`tryRemake` / close 后再编）。
- **HTTP**：`isSafeHeaderValue` 禁单字段 CR/LF；`contentType` 不安全回退默认；客户端 method/path/host 拒注入；`Transfer-Encoding: chunked` 编解码 + `HttpResponse.chunked`；`setMaxBytes`（硬顶 64MiB，默认 8MiB）。
- **CHM**：16 段条带锁（`hash.hashOf % 16`）；跨段 `size/keys/values/clear` 按段序加锁。
- **GC**：多轮协作 STW（Win 仍禁 SuspendThread）；仅最终未齐 park 才全标活；`hao_gc_is_heap_ptr` 持锁查堆链。

**验收**：套件 **954**；negcheck **28/28**；`hao version`=0.43.0。

### v0.42.1（2026-08-08）· 回归审计修复（JSON/HTTP/64 混算/并发安全）

> **目标**：审计发现的高/中风险一次修完，正反向用例入库，不将就。

- **JSON**：`\b`/`\f`/`\uXXXX` 按 `Char` 拼接（禁 `String+Int` 十进制）。
- **类型**：已 64 位有符号/无符号混算/比较/位运算 → 编译拒绝（`binaryNumericPromote`/`binaryBitwisePromote` 返空）；negcheck +4。
- **HTTP**：头/体分隔与 CL 一律字节下标；CL **行首锚定**；`writeResponse` 拒不安全头块（防 CRLF 注入）。
- **channel**：同盒 remake 拒绝（防 UAF）；仅堆指针挂 GC 根。
- **net/dynload**：`hao_net_ensure` / `hao_k32_bootstrap` 原子 once 初始化。
- **CHM**：全部公开方法 `try/finally` 解锁。
- **regex**：单次匹配步数上限 `HAO_RE_MAX_STEPS`（防 ReDoS）。
- **reflect**：arity/方法不存在 → `Exception`（与合法返回 0 可区分）；C 层防御 panic。

**验收**：套件 **936**；negcheck **28/28**；`hao version`=0.42.1。
