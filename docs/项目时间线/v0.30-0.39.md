### v0.37.0（2026-08-08）· 多线程自动 GC（协作 safepoint，清债 G）

> **目标**：彻底去掉 `gc_thread_count≤1` 门闩；worker/haoroutine 存活期间阈值亦可自动 STW。

- **协作 STW**：`hao_gc_safepoint()`；置 request 后**释放 GC 锁**等 park，再加锁扫描（否则 mutator 堵在 crit_enter 永难 park）。

- **TLS**：每线程 `gpr_spill` + `park_sp`；park 时溅射 GPR 再保守扫栈。
- **未齐 park**：本轮全标活不回收（防漏扫 UAF）；禁止依赖异步 Suspend（Win 易 AV）。
- **门闩删除**：`gc_alloc_ex` 阈值 minor/major 与线程数无关。
- **套件**：`v20GCTest` 断言 `collectCount` 在多线程分配中上升（`v20 autoGc=true`）；基线 **921**。

**文件**：`runtime_gc.c`/`runtime_winapi.c`/`runtime_internal.h`；`IRGenControl.cpp`/`IREmitter.h`；`v20.hao`/`gcv3.hao`/`GC.hao`；`VERSION` 0.37.0。
