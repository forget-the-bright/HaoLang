## 维护约定

1. **升版或本版专节**：写入对应十位合订文件（如 `0.36.0` → `v0.30-0.39.md` 文首插入专节），并更新本索引表一行。
2. **记忆文档 / README** 只保留当前版本摘要 + 指向本目录的链接，不复制整段专节。
3. 同大版本补丁（`0.21.0` / `0.21.1`）写在同一合订文件内相邻专节。
