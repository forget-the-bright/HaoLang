### v0.9.0（2026-08-06）· 重载 + fmt 库化 + 泛型方法 + 集合

四个特性落地并全量测试通过：
1. **函数重载**——同名按参数个数/类型区分，调用点 `selectOverload` 选最佳匹配（精确优先，Int→Double 提升）；IR 名带签名后缀。
2. **fmt 迁成 `.hao` 包**——`stdlib/src/fmt/fmt.hao`（4 个 extern println 重载 + print）；`fmt.println(x)` 无需 `import fmt`（编译器隐式预导入 + 自动加载）。
3. **泛型方法**——`List<T>.map<R>` 方法级类型参数单态化；`List.map/filter/forEach` 现为标准库方法。
4. **Map/Set/Queue**——开放寻址 + `stdlib/runtime_hash.c`（extern 调用）；key 第一版限 Int/Double/Bool/String。

**实现细节与坑**（详见表下）：
- 重载：`overloads_` 表 + `overloadSuffix`（IR 符号名带签名后缀防 clang 重定义）+ `genFunction` 按 AST 签名选符号。
- 泛型方法：模板登记在 `instantiateClass`；`currentTypeParams_` 须含类级+方法级、`currentPkgPrefix_` 须切模板前缀；`applyMethodCall` 补压 `expectedTypes_`。
- 集合：`resize()` 须先 `count=0`；`X!!.field=` 不是合法左值，先取临时引用。

### v0.8.0（2026-08-06）· extern C 声明 + 统一异常基类

- **extern C 函数声明**：`extern func f(x:Int):Unit = "c_name";` —— 无函数体、`= "..."` 指定 C 符号名（省略用短名）。编译器自动输出 `declare`，与内建运行时声明去重（`IREmitter::isRuntimeDeclared`）；调用直接 `call @c_name` 零开销。**这是标准库 .hao 化的前置卡点，已打通。**
- **统一异常基类** `exception.Exception`（纯 `.hao`，stdlib/src/exception/）：带 `message`/`getMessage()`/`toString()`；用户自定义异常继承它，`catch(Exception)` 按虚表 typeids 天然捕获所有子类，编译器零改动。

### v0.7.0（2026-08-06）· 函数式集合 + List<T>

> **核心难点**：泛型函数从 `(T)->R` 形参**递归推断嵌套类型参数**（map 的 R 从 lambda 返回类型推断）。

- 新增 `unifyWithArg`（递归合一 TypeParam/Array/Func）+ `callGenericFunction`（**两遍实参求值**：先求非 lambda 实参建 T，再把未解析的 R 置空作期望类型让 lambda 自推返回类型，再合一绑定 R）。
- 标准库 `collections.List<T>`（第一个纯 .hao 标准库包）；`map/filter/forEach/reduce`；字段数组 `+=` push 与 `obj.arr[i]=` 赋值。
- **坑**：`isEmptyArrayLiteral` 参数类型是 `ExprContext*` 但赋值右值是 `AssignExprContext`（不派生自 Expr），`dynamic_cast` 得空 + arrayLiteral 含 `[` `]` 两孩子单子下降提前停 → 改 `ParseTree*` + DFS。

### v0.6.0（2026-08-06）· 多文件 / 包 / import

Go 风格"目录即包、整盘编译"：一个目录是一个包，import 的点分路径映射到子目录，整个 import 闭包解析成多棵 AST 后交给 IRGen **一次性**生成一份 IR。

- 入口语义：传**文件**只编译列出的文件（`go run a.go b.go`）；传**目录**编译该包全部 `.hao`。
- import 查找：先相对入口目录找子目录，再找编译器自带 `stdlib/src/<path>`。
- **IR 符号加包前缀**：非 main 包顶层符号加前缀（`/`→`$`，如 `util/strings` 的 `join` → `@util$strings$join`）；main 包前缀为空，老测试零改动。
- 两阶段收集（阶段 A 登记类型名、阶段 B 解析成员）解决跨包类型前向引用。
- **坑**：显式文件入口不能扫目录（否则 test/ 下 14 个 main 冲突）；每个包建 `pkgExports_[importPath]` 空条目；泛型实例生成前后保存/恢复 `currentPkgPrefix_`；`-o` 显式路径原样使用（自动推导名才加 `.exe`）。
