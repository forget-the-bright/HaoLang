### v0.79.0（2026-08-14）· 系统库分层激进对齐（禁 PARTIAL）

> **根因**：对标 Go/Java/C# 时把 Object/float/reflect 拼串/`hao_str_*` 算法仍留 C 当成可挂 PARTIAL。
> **硬修**：M5 删死导出；M2 Object 三默认 Hao；M1 Float/Double toStr+parse Hao；M3 field_bits+Hao toStr；M4 len/char_at/byte_of_cp/concat 迁 Hao（concat→SB）。方法论 §7 铁律+清单。
> **验收**：stringbuilder/sb_gc/negcheck；suite **1052**；latency；`hao version`=0.79.0。

### v0.78.0（2026-08-13）· str_len UAF 根治 + 废数组 +=/pop

> **根因**：① `hao_str_byte_arr` 内部别名跨 `ensureCapacity` GC → 偶发 `hao_str_len 非法指针`；② 故意 panic 只 `fprintf`+`abort` 不落 `hao-crash.log`；③ 语言仍留数组 `+=`/`pop`→`hao_array_push` 半套（违 Java/C#）。
> **硬修**：SB.append 先 `get_bytes` 再扩容；删 `hao_str_byte_arr`；故意 fatal→`hao_report_fatal`；IR 拒数组 `+=`/`pop`；删 C push/pop；suite 迁 ArrayList；`sb_gc_gate`。
> **验收**：stringbuilder/sb_gc/negcheck40；suite **1050**；latency jsonP95≤8；`hao version`=0.78.0。

### v0.77.0（2026-08-13）· 数组/StringBuilder 对齐 Java/C#

> **根因**：Go 式 len/cap + 公开 capacity/`+=`；v0.76 再堆 C `append_*`/`ensure_cap` 违方法论。
> **硬修**：定长数组；`hao_arraycopy`；`Arrays.copyOf*`；`ArrayList(elementData+count)`；`StringBuilder(value+count)` 全 Hao；stdlib 清 `table+=null`/收集 `+=`；废公开 `array.capacity`。
> **验收**：stringbuilder_gate；分层单测；全量+negcheck；latency jsonP95≤8；`hao version`=0.77.0。

### v0.76.0（2026-08-13）· StringBuilder 根治 + JSON-BEAN-CG

> **根因**：不可变 `String` 正确；缺 `StringBuilder` + `hao_str_concat` exact-fit → 循环 `+`/假 Buf Θ(n²)；JsonBuf 碎片树、ByteBuf `data=data+` 假缓冲。
> **硬修**：`lang.StringBuilder`/`StringBuffer`（`[Byte]` 几何扩容；C 仅 `hao_array_ensure_cap`/`append_*`）；JsonBuf/ByteBuf/`quoteInto` 建在 SB 上；IRGen `@Class.$jsonWrite` + meta `jsonWrite` + `hao_json_try_write` 跳板。
> **禁止**：`hao_str_builder_*`、半套只交 `$jsonWrite`、砍字段/手写 `toJson` 装绿。
> **验收**：`stringbuilder_gate`；http_lat source；latency **jsonP95≤8** 全量字段；套件 1052；`hao version`=0.76.0。

### v0.75.2（2026-08-13）· JSON-BEAN：反射热路径治本（对标 Fastjson ObjectWriter）

> **承认**：0.75.1 手写 `GcSnapshot.toJson` 仍是旁路治标。
> **设计债**：`getField(name)` 线性查找 + 每次 quote/类型串；未对标 Java Fastjson `ObjectWriter` / .NET `JsonTypeInfo` 缓存。
> **硬修**：`field_get_at` 按索引读；`JsonBeanInfo` 按类缓存 quotedKey+kind；默认 `/api/gc` 回 `toJSONString`；删手写 toJson。
> **验收**：全量字段 + jsonP95≤20（反射路径）；source 禁 `snap.toJson` 回潮。
> **仍开（正道下一刀）**：IRGen/`$jsonWrite` 源码生成（对标 .NET STJ source-gen / Fastjson ASM），目标个位数 ms。
