# HaoLang VSC# HaoLang VSCode 插件完整功能清单（LSP + Debug + 语法支持 + 工程工具全覆盖）
整体分为 5 大模块：**语法基础支持、LSP语言服务、Debug适配器(DA)、工程构建集成、辅助UI体验**。
> 架构建议：标准分离方案
> - `haolang-lsp`：独立进程（HaoLang/C++编写，LSP Server）
> - `haolang-debug-adapter`：独立进程（Debug Adapter）
> - VSCode Extension（Typescript）：薄壳，负责通信、激活、配置、UI绑定

## 一、基础语法静态支持（不依赖LSP也能基础可用）
1. **文件识别**
    - 注册 `.hao` 文件后缀，绑定语言ID `haolang`
    - 识别 shebang `#!/usr/bin/env hao`
    - 区分源码文件 / 模块清单文件 / 配置文件（如 `hao.toml`）
2. **语法高亮 TextMate 语法**
    - 关键字、类型、修饰符、函数、变量、泛型、闭包、字符串插值 `@$expr`
    - 注释单行 `//`、多行 `/* */`、文档注释 `///`
    - 字面量：整数、浮点数、布尔、字符串、原始字符串、字符
    - 运算符、分隔符、泛型 `<>`、模式匹配语法
    - 区分类型名、函数名、局部变量、常量、静态变量着色
3. **括号匹配**
    `() [] {} <>` 高亮配对
4. **自动括号补全**
    引号、括号、大括号自动闭合
5. **代码折叠**
    函数体、结构体、if/for、块注释、文档注释区域折叠
6. **缩进规则**
    回车自动对齐，支持配置 Tab / 空格缩进大小
7. **代码片段 Snippets**
    `fn`、`struct`、`if`、`for`、`match`、`impl`、`import`、`test` 等模板

## 二、LSP 语言服务器核心能力（重中之重，haolang-lsp 实现）
遵循 LSP 3.17 标准，LSP Server 读取源码、构建AST、类型检查、符号索引。
### 2.1 文档基础能力
1. **文档打开/保存/增量文本更新（didChange）**
    增量更新，不要每次全量重解析；支持脏文件实时分析
2. **语法错误、类型错误诊断（Diagnostic）**
    - 词法错误、语法解析错误
    - 类型不匹配、未定义标识符、泛型参数错误
    - 未使用变量、导入、函数（lint警告）
    - 错误范围标记、提示消息、错误代码
    - 保存时自动刷新诊断
3. **悬浮提示 Hover**
    - 变量：类型、来源、文档注释
    - 函数：签名、参数说明、返回值、文档注释
    - 结构体/枚举：字段列表、文档
    - 泛型实参展开信息
4. **跳转定义 Go to Definition**
    - 变量、函数、结构体、枚举、导入符号跳转
    - 支持跨文件、跨模块跳转
5. **跳转类型定义 Go to Type Definition**
    变量 → 对应类型声明位置
6. **查找引用 Find References**
    全局列出所有读取/写入位置，区分读引用、写引用
7. **文档符号 Outline（大纲视图）**
    函数、结构体、枚举、常量、全局变量分层展示
8. **工作区符号搜索 Workspace Symbol**
    Ctrl+T 全局搜索任意符号

### 2.2 代码补全 Completion
1. 局部变量、参数、常量补全
2. 导入模块、导出符号补全
3. 结构体字段访问 `.` 触发补全
4. 方法调用补全（impl 方法）
5. 泛型参数提示
6. 内置类型、标准库函数补全
7. 关键字、修饰符补全
8. 导入自动补全候选

### 2.3 代码操作能力
1. **签名提示 Signature Help**
    函数调用括号内显示参数列表、当前高亮参数
2. **重命名符号 Rename Symbol**
    安全重构：变量/函数/结构体全局批量重命名（跨文件）
3. **代码格式化 Format Document / Format Selection**
    LSP内置调用 `hao fmt` 或者内置格式化器
4. **代码动作 CodeAction（QuickFix）**
    - 自动添加缺失 import
    - 删除未使用导入、未使用变量
    - 类型提示补全
    - 快速实现缺失impl方法
    - 修复简单语法错误
5. **文档链接 DocumentLink**
    源码内路径链接、文档URL跳转
6. **语义高亮 Semantic Tokens（增强着色）**
    超越TextMate：区分本地变量/参数/静态/函数/类型/泛型参数，主题精准着色

### 2.4 模块 & 工作区支持
1. 识别 `hao.toml` 工程根目录，多模块工作区加载
2. 依赖模块索引（标准库 + 第三方包）
3. 导入路径校验、模块不存在诊断
4. 工作区变更监听：新增/删除`.hao`文件自动重建索引

## 三、Debug 功能（Debug Adapter Protocol，独立 Debug Adapter）
> 方案：你的 `hao.exe` 支持 lldb/gdb 底层调试 或者 内置自定义调试协议；DA作为中间层对接VSCode DAP
### 3.1 基础调试控制
1. 启动调试 launch 配置（直接运行 `hao run`）
2. 附加调试 attach（附加到正在运行的hao进程）
3. 继续、暂停、单步进入 stepIn、单步跳过 stepOver、单步跳出 stepOut
4. 重启调试、终止调试会话

### 3.2 断点体系
1. 源码行断点
2. 条件断点（满足表达式才中断）
3. 命中计数断点
4. 日志断点（不暂停，打印消息）
5. 支持禁用断点
6. 识别源码位置映射（IR/LLVM生成代码 ↔ HaoLang源码）【极其关键】

### 3.3 变量 & 求值
1. 局部变量、函数参数、全局变量查看
2. 结构体、数组嵌套展开查看字段
3. 监视窗口 Watch：输入HaoLang表达式实时求值
4. 悬停查看变量值（集成Hover）
5. 支持简单变量修改（Set Variable）

### 3.4 调用栈
1. 调用栈展示，点击栈帧跳转对应源码
2. 区分用户代码 / 标准库代码（可过滤）
3. 栈帧源码位置映射（核心难点，依赖DWARF调试信息）

### 3.5 额外调试增强（适配你的GC语言）
1. GC相关可选断点（GC开始、GC结束、内存分配断点）
2. 查看GC堆统计、句柄NativeHandle资源信息（自定义DAP扩展事件）
3. 协程/线程列表查看（如果实现协程调度）

### 3.6 Launch 配置模板
插件内置 `.vscode/launch.json` 模板：
- 直接运行当前文件
- 构建并调试目标模块
- 启用GC日志、诊断模式参数传递给hao.exe

## 四、工程命令集成（调用 hao CLI）
注册 VSCode 命令，调用本地 `hao` 命令行工具
1. `hao build` 构建项目
2. `hao run` 运行当前模块
3. `hao test` 执行单元测试
4. `hao fmt` 格式化代码
5. `hao check` 静态类型检查（不生成二进制）
6. `hao doc` 生成文档
7. `hao clean` 清理构建产物
8. `hao add / hao remove` 管理依赖包

### 配套体验

- 终端自动调用hao，捕获编译错误，点击跳转源码
- 检测本地是否安装 `hao`；未安装给出下载提示
- 支持配置 `hao` 可执行文件自定义路径（设置项）

# 关键技术风险提醒（针对你的HaoLang）
1. **LSP性能**：增量解析、AST缓存，大工程避免每次全量重解析；
2. **调试最大难点**：**DWARF调试信息完整性**，IR/LLVM生成时必须准确映射 HaoLang源码行号；否则断点乱跳；
3. **跨进程通信**：Extension ↔ LSP ↔ DebugAdapter 三者进程隔离，注意进程生命周期管理（窗口关闭自动杀掉服务）；
4. **自举友好**：LSP 未来尽量能用 HaoLang 自举实现；初期可以先用C++ bootstrap版本。
