# 文档治理

> 目标：**单文件不再无限膨胀**；职责清晰；**不重复**；规则始终可在记忆文档找到。

## 文档地图

| 文档 | 读者 | 写什么 | 不写什么 |
|------|------|--------|----------|
| [`../README.md`](../README.md) | 用户 / 对外 | 项目介绍、快速开始、语法与用法摘要、正向/反向示例、已知限制摘要、构建测试入口；**详文链到 docs/** | 版本专节全文、IRGen 时序、完整坑表、将就债细节 |
| [`../记忆文档.md`](../记忆文档.md) | 接手 AI | **工作规则**、接入清单、防回归、设计决策**摘要**、特性/库速查、代码地图、构建细节、限制摘要、下一批、批末清单 | 冗长用户教程、完整版本专节、完整踩坑表、**整份 IR↔GC 契约** |
| [`IR与GC契约.md`](IR与GC契约.md) | 改 IRGen / GC | **埋点、流程、R 规则、指标、检查清单**（GC 权威详文） | 版本流水账、用户语法教程 |
| [`hao命令.md`](hao命令.md) | 用户 / 工具链 | `hao` 各子命令原理与选项；**包管理**字段/环境变量/生效方式；`hao test` 规则（对标 go test） | IRGen 内部、版本流水账 |
| [`hao语法.md`](hao语法.md) | 用户 / 迁移者 | 语法与语义说明；限制；**对标 Go/Java/C#** | 命令行细节、完整 stdlib API 列表 |
| [`项目时间线/索引.md`](项目时间线/索引.md) | 查历史 | 各版本「做了什么」；同十位大版本合订（如 `0.20.*`～`0.29.*` → `v0.20-0.29.md`） | 规则条文、坑表全文、契约全文 |
| [`坑债.md`](坑债.md) | 修 bug / 清债 | 踩坑表（现象→原因→解法）、将就债、构建类速查 | 特性教程、版本里程碑叙述、契约全文 |

**同频字段**（改一处必核其它）：版本号、套件基线行数、negcheck 数、下一步任务、用户可见限制。

## 必读顺序（新会话）

1. 记忆文档 **第 0～1 章**（含全部工作规则）
2. 记忆文档 **将就债指针** → [`坑债.md`](坑债.md) 第二节
3. 记忆文档 **第 10 章**（下一批默认任务）
4. 动手时再查：坑债 · 代码地图 · 设计决策 · 时间线合订

## 批末写哪里

```
.bak → 改代码 → 测试绿 → 立刻写文档 → 删 .bak → 下一块
```

| 时机 | 落盘位置 |
|------|----------|
| 完成项（本版做了什么） | `项目时间线/v0.XX-0.YY.md` 专节 + 记忆文档 0.5 摘要 + README 进度一行 |
| 踩坑 | **仅** [`坑债.md`](坑债.md)（现象→原因→解法）；README / 记忆文档只链过去 |
| 将就 | **仅** [`坑债.md`](坑债.md) 第二节；记忆文档 9.2 保持指针 |
| 新设计决策 | 记忆文档第 5 章（摘要）；**IR/GC 埋点与流程**只写进 [`IR与GC契约.md`](IR与GC契约.md) |
| GC / 写屏障 / STW 变更 | **先**更新 `IR与GC契约.md`，再改记忆文档 §5.4 摘要 + 坑债一行 + 时间线专节 |
| 用户可见语法/限制变化 | README 对应节 + 记忆文档第 3/9 章摘要 |

- 进入下一十位时新建合订，勿把旧合订继续灌胖。

## 篇幅边界（中度梳理后）

- **README**：短首页。可保留快速开始、命令表、构建/测试/打包入口、限制摘要；**不写**完整语法教程与完整 stdlib API（链到 `hao语法` / `hao命令` / 源码注释）。
- **记忆文档第 3～4 章**：只留**速查表**；详文在 `hao语法`、stdlib 文件头、时间线专节。
- **用户详文权威**：`hao命令.md`（CLI/包管理）、`hao语法.md`（语义/对标）。

## 禁止

- 在 README 与记忆文档之间复制整段时间线或整张坑表
- 在 README / 记忆文档再展开与 `hao语法` / `hao命令` 同级的长教程
- 只改代码不写文档，或只更新一份文档
- 把聊天原文粘进记忆文档
- 用「文档写了限制」代替清将就债
