# 文档治理

> 目标：**单文件不再无限膨胀**；职责清晰；**不重复**；规则始终可在记忆文档找到。
>

**冲突优先级（强制）**：运行时 / IRGen / GC **实现**以 [`IR与GC契约.md`](IR与GC契约.md) + 记忆文档第 5 章**已定决策**为准。方法论与契约或已定决策冲突时，**不得**以方法论覆盖实现口径；只允许把差距记进时间线 / 记忆第 10 章 / 坑债将就债。

**同频字段（最小集，改一处必核其它）**：根目录 `VERSION`、套件基线行数、negcheck 数、下一批指针。用户可见限制有变时再动 README / 记忆第 9 章。补丁号细节只写时间线合订与坑债专节；对外/速查层只引用 `VERSION`。`hao-crash.log` 字段名以 [`hao命令.md`](hao命令.md) §2.2.1 为准（`time=`/`where=`/`hao_stack`/`native_stack`）。

1. 记忆文档 **第 0～1 章**（含全部工作规则）

4. 动手时再查：坑债 · 代码地图 · 设计决策 · 时间线合订

## 批末写哪里

```
.bak → 改代码 → 测试绿 → 立刻写文档 → 删 .bak → 下一块
```

| 时机 | 落盘位置 |
|------|----------|
| 完成项（本版做了什么） | `项目时间线/v0.XX-0.YY.md` 专节 + 索引一行 + 记忆文档 0.5 **一行摘要** + README 抬头 **一行** |
| 踩坑 | **仅** [`坑债.md`](坑债.md)（现象→原因→解法）；README / 记忆文档只链过去 |

| 新设计决策 | 记忆文档第 5 章（摘要）；**IR/GC 埋点与流程**只写进 [`IR与GC契约.md`](IR与GC契约.md) |
| 架构 / 分层 / 收口原则 | [`方法论/`](方法论/)；差距与改造方案可落时间线或记忆文档第 10 章，**勿**把整份方法论粘进记忆文档 |
| GC / 写屏障 / STW 变更 | **先**更新 `IR与GC契约.md`，再改记忆文档 §5.4 摘要 + 坑债一行 + 时间线专节 |
| 用户可见语法/限制变化 | README 对应节 + 记忆文档第 3/9 章摘要 |
| 类型生命周期 / 四属性 / 去 C 化路线 | **先**更新 [`类型属性.md`](类型属性.md)；hao语法 §4.0 只留短节；差距进坑债将就债 |

## 篇幅边界

- **README**：短首页。可保留快速开始、命令表、构建/测试/打包入口、限制摘要；**不写**完整语法教程与完整 stdlib API（链到 `hao语法` / `hao命令` / 源码注释）。
- **记忆文档第 3～4 章**：只留**速查表**；详文在 `hao语法`、stdlib 文件头、时间线专节。
- **用户详文权威**：`hao命令.md`（CLI/包管理）、`hao语法.md`（语义/对标）。

## 禁止

- 在 README / 记忆文档再贴与本文件同级的**完整文档地图表**（只保留短指针）
- 在 README 与记忆文档之间复制整段时间线或整张坑表
- 在 README / 记忆文档再展开与 `hao语法` / `hao命令` 同级的长教程
- 只改代码不写文档，或只更新一份文档
- 把聊天原文粘进记忆文档
- 用「文档写了限制」代替清将就债
- 用方法论覆盖 `IR与GC契约` 或记忆 §5 已定决策
