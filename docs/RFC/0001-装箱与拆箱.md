# RFC-0001：装箱与拆箱

| 字段 | 值 |
|------|-----|
| 状态 | **Implemented** |
| 版本锚点 | v0.59.0 |
| 对标 | Java 自动装箱/拆箱；**不是** C#「值类型直接箱到 Object」 |

## 1. 动机

区分**原生值类型**（栈槽、无对象头、不属于 `Object`）与**包装引用类型**（堆对象、继承 `Object`）。需要把值交给 `Object` / 泛型引用槽时，必须经匹配包装类。对标 Java，避免 C# 式「任意值类型一步箱成 `object`」与数值拓宽混链。

## 2. 语法规范

| 形态 | 写法 |
|------|------|
| 隐式装箱 | `var box: Integer = a;`（`a: Int`） |
| 显式装箱 | `Integer.valueOf(a)` 或 `a as Integer` |
| 自动拆箱 | `var raw: Int = box;` |
| 顶层 Object | `var o: Object = a;` ≡ 先匹配包装再向上转型 |
| 非法 | `var L: lang.Long = someInt;`（拓宽+装箱合并） |
| 正交 | `Int?`（`hao_box_*` 可空值）**不是** `Integer` |

匹配对（节选）：`Int`↔`Integer`，`Long`↔`lang.Long`，`Bool`↔`Boolean`，`Double`↔`lang.Double`，以及其它 `lang` 数值包装。

## 3. 编译转换

1. 目标为对应包装、源为原生 → 插入 `valueOf`（或等价 IR 调用）。
2. 目标为原生、源为对应包装 → 插入 `*Value`（如 `intValue`）。
3. 目标为 `Object`、源为原生 → 装箱到匹配包装，再按引用向上。
4. `as` 到包装/原生：显式路径；运行时类型不符 → panic（见约束）。

门禁：`target/p10-smoke`（`box_*`）；`negcheck` 装箱链式拒绝。

## 4. 语义约束

- 拆箱**只能**拆到原始匹配原生类型；**禁止**「拆箱 + 隐式数值转换」一步完成（如 `Integer` → `Long`）。
- **禁止** `Int` → `lang.Long` 一步（不能数值拓宽与装箱合并）。
- `Object o = 10;` 实际类型是 `Integer`；`o as Long` / `o as lang.Long` **运行时 panic**（不能先当 Long 拆）。
- 正确宽化：`(o as Integer)!!.longValue()` 或先拆到 `Int` 再显式转 `Long`。

## 5. 示例

### 5.1 正例

```hao
var a: Int = 10;
var box: Integer = a;
var box2: Integer = Integer.valueOf(a);
var raw: Int = box;
var o: Object = a;
fmt.println(o is Integer);
```

### 5.2 反例

```hao
// 编译拒绝：Int → lang.Long 包装链
// var bad: lang.Long = 10;

// 运行时 panic：实际是 Integer
// var o: Object = 10;
// var v = o as Long;
```

## 6. 歧义分析

| 概念 | 是否新建对象 | 说明 |
|------|----------------|------|
| 装箱 | **是** | 原生 → 包装堆对象 |
| 向上转型 | 否 | 仅引用静态视图（见 RFC-0002） |
| `T?` 可空 | 实现可箱 | 语言分类仍是可空**值**，≠ 包装类 |
| 隐式数值转换 | 否 | 仅栈上拓宽/收窄，与装箱独立 |

三种隐式转换**互不链式合并**：数值转换 / 装箱 / 向上转型。
