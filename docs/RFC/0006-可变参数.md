# RFC-0006：可变参数 `T...`

| 字段 | 值 |
|------|-----|
| 状态 | **Implemented** |
| 版本锚点 | v0.60.3 |
| 对标 | Java `T...`；底层隐式 `new`（见 RFC-0005） |

## 1. 动机

调用处展开多个同型实参，避免手写 `new [T]{…}`；与数组模型正交：形参在函数内就是 `[T]`，可上转型 `Array`。

## 2. 语法规范

```hao
func Sum(values: Int...): Int
```

| 规则 | 口径 |
|------|------|
| 位置 | **必须末位** |
| 个数 | 至多一个 `...` |
| 函数内类型 | `[T]` |
| 调用 | `Sum(1,2,3)` / `Sum(new [Int]{1,2,3})` / `Sum()`（仅当无固定前缀） |
| 具名 | 可变段 **禁止**具名实参 |

非法：`func F(a: Int..., b: Int)`；`func G(a: Int..., b: Int...)`；`Sum(values: 1)`。

## 3. 编译转换

1. 形参符号化：`values` 类型 = `makeArray(T)`，标记 `isVarArg`。
2. 调用：固定前缀按既有绑定；尾部：
   - 若剩余实参恰为一个且类型已是 `[T]`（或可赋给 `[T]`）→ **直传**（不分配）；
   - 否则将剩余实参打包为隐式 `new [T]{…}`（空则 `new [T]{}`）。
3. 隐式 new 是 RFC-0005 下**唯一**允许调用方省略 `new` 的路径。

## 4. 语义约束

- 打包路径得到**独立**新数组实例；直传共享调用方数组引用。
- 与具名实参（RFC-0004）：可变槽禁止标签。
- 值类型 / 对象数组不引入不安全隐式转型（元素规则同普通 `[T]`）。

## 5. 示例

### 5.1 正例

```hao
func Sum(values: Int...): Int {
    var s = 0;
    var i = 0;
    while (i < values.length) {
        s = s + values[i];
        i = i + 1;
    }
    return s;
}
fmt.println(Sum(1, 2, 3));
fmt.println(Sum(new [Int]{1, 2, 3}));
fmt.println(Sum());
```

### 5.2 反例

```hao
// func Bad(a: Int..., b: Int) {}
// Sum(values: 1, 2);
```

## 6. 歧义分析

| 写法 | 含义 |
|------|------|
| `Sum(arr)` 且 `arr: [Int]` | 直传 |
| `Sum(1)` | 打包 length=1 的新数组 |
| `[...a]` 在 `new [T]{…}` 内 | 字面量展开，不是形参 `T...` |
| C# `params` | Hao 用 `T...`，不做 `params` 关键字 |
