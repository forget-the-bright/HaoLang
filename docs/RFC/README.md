# HaoLang RFC 索引

> **语言特性集成权威**。用户速查仍看 [`../hao语法.md`](../hao语法.md)；实现埋点看契约/时间线/坑债。  
> 职责地图见 [`../文档治理.md`](../文档治理.md)。

## 状态约定

| 状态 | 含义 |
|------|------|
| **Draft** | 讨论中，不可当实现承诺 |
| **Accepted** | 语义拍板，待实现或实现中 |
| **Implemented** | 已交付；示例与门禁可复验 |
| **Rejected** | 明确不做（须写清替代） |

## 强制结构（每篇）

动机 → 语法规范 → 编译转换 → 语义约束 → 示例 → 歧义分析  
空模板见 [`模板.md`](模板.md)。

## 维护约定

1. 新特性：先 RFC（至少 Accepted）再合入语法矩阵「已交付」。
2. `hao语法.md` 只留短节 + 链到本目录；禁止在多处复制整篇 RFC。
3. 实现变更若改语义：先改对应 RFC，再改代码与门禁。
