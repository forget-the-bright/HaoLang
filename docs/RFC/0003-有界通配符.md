# RFC-0003：有界通配符（PECS）

| 字段 | 值 |
|------|-----|
| 状态 | **Implemented**（主路径）；完整 capture conversion 边角见坑债 **WILD-CAP** |
| 版本锚点 | v0.59.0 |
| 对标 | Java `?` / `? extends` / `? super`；**明确不做** C# 声明处 `in`/`out` |

## 1. 动机

集合 API 需要「只读生产者 / 只写消费者」视图，而不复制数据。选 **方案 A（Java 通配）** 以对齐 Java 生态；拒绝方案 B（接口变体 `in`/`out`）以避免双轨。

## 2. 语法规范

| 写法 | 含义 |
|------|------|
| `List<?>` | 无界通配 |
| `List<? extends Animal>` | 上界；生产者，读取为 Animal 侧 |
| `List<? super Dog>` | 下界；消费者，可写入 Dog 及子类 |
| `where T : Animal` | 类型参数约束（与通配不同层，见歧义） |

非法：对 `? extends` 视图 `add` 非 null 元素；对 `? super` 读作具体子类型（静态只能当更抽象类型使用，实现上 get 侧按 PECS）。

## 3. 编译转换

- 文法 `typeArg`：`type` \| `?` \| `? extends type` \| `? super type`。
- `isAssignable` / 调用实参：PECS 赋值与 `add`/`get` 检查。
- 门禁：`target/p10-smoke`（`wild_extends` / `wild_super` + neg）。

## 4. 语义约束

1. `List<Dog>` 可赋给 `List<? extends Animal>`。
2. `List<? extends Animal>` **禁止** `add` 任意非 null（编译拒）。
3. `List<? super Dog>` 允许写入 `Dog`（及子类）；读取侧不提供「确定为 Dog」的静态类型。
4. **不做**声明处协变/逆变 `in`/`out`。
5. 通配与装箱：`List<? extends Object>` 上 `add(10)` 仍因上界通配禁写而拒绝（不是装箱问题）。

## 5. 示例

### 5.1 正例

```hao
val dogs = new ArrayList<Dog>();
dogs.add(new Dog());
val view: List<? extends Animal> = dogs;
val a: Animal = view.get(0);
```

### 5.2 反例

```hao
val view: List<? extends Animal> = new ArrayList<Dog>();
// view.add(new Dog());  // 编译拒绝
```

## 6. 歧义分析

| 机制 | 作用点 | 说明 |
|------|--------|------|
| `? extends` / `? super` | 使用处类型实参 | PECS 读写限制 |
| `where T : C` | 声明处类型参数 | 约束可实例化的 T |
| C# `in`/`out` | 声明处变体 | **Rejected**（本语言） |
| 装箱 | 值↔包装 | 与通配独立；通配禁写优先 |

完整 Java capture conversion 边角：**不阻塞主路径**；差距记坑债 WILD-CAP。
