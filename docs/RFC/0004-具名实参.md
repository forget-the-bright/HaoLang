# RFC-0004：具名实参

| 字段 | 值 |
|------|-----|
| 状态 | **Implemented** |
| 版本锚点 | v0.60.1 |
| 对标 | Swift/C# 风格 `name: expr`；非 Kotlin/Python `=` |

## 1. 动机

调用处按形参名绑定，减少位置错误；文法早已接受 `(IDENT COLON)? expr`，须补语义，禁止继续「丢掉标签当位置参数」的静默错绑。

## 2. 语法规范

| 规则 | 口径 |
|------|------|
| 写法 | `f(a: 1, b: 2)` |
| 标签 | = 形参名 |
| 混用 | 仅「位置前缀 + 具名后缀」；`f(b: 1, 2)` 非法 |
| 乱序 | 具名之间可乱序 |
| 元数 | 精确匹配（本 RFC **不含**默认参数） |
| Func 值调用 | **禁止**具名 |
| `new [T](n[,fill])` | 保持位置内建 |

注解成员仍用 `name = expr`，与调用具名 `:` 区分。

## 3. 编译转换

1. `bindCallArgs(argList, paramNames)` → 有序槽位向量。
2. 求值顺序：源码从左到右，再写入槽。
3. 重载：绑定后再走既有 `selectOverload`。
4. 错误：未知名 / 重复名 / 具名后跟位置 / 同槽冲突 / 缺参 / Func 值具名。

门禁：`target/p12-smoke` + `p5_smoke` P12。

## 4. 语义约束

- 不得静默忽略标签。
- 不做默认参数、不做 `=` 具名、不做反射 invoke 具名映射。

## 5. 示例

### 5.1 正例

```hao
func area(w: Int, h: Int): Int { return w * h; }
fmt.println(area(h: 3, w: 4));
fmt.println(area(2, h: 5));
```

### 5.2 反例

```hao
// area(h: 3, 4);           // 具名后位置
// area(w: 1, w: 2);        // 重复
// area(width: 1, h: 2);    // 未知名
```

## 6. 歧义分析

| 写法 | 含义 |
|------|------|
| `f(x: 1)` | 实参标签 `x` |
| `f(x: Int)` | 标签 `x`，表达式为类型名 `Int`（少见，合法标识符表达式） |
| 注解 `x = 1` | 不是调用具名 |
| 默认参数 `x: Int = 0` | 文法可解析，**语义未实现**（另案） |
