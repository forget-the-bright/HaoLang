# RFC-0007：自动属性增强

| 字段 | 值 |
|------|-----|
| 状态 | **Implemented** |
| 版本锚点 | v0.60.3 |
| 对标 | C# 自动属性 + 访问器可见性；OnChange 为 Hao 极简降糖 |

## 1. 动机

v0.58 已支持 `get;`/`set;` 自动属性，但缺默认值、自定义存取器体与 accessor 级可见性，无法从「薄属性」平滑演进到校验/通知。

## 2. 语法规范

```hao
var name: String { get; set; } = "x";
val id: Int { get; } = 0;
var items: [Int] { get; set; } = new [Int]{};
var score: Int { get; protected set; }
var title: String {
    get { return _storage; }
    set {
        Validate(value);
        _storage = value;
    }
}
var name: String { get; set; } OnChange(onNameChanged);
```

| 规则 | 口径 |
|------|------|
| `=` 初值 | 可选；语义同字段初始化 |
| 数组默认 | 必须 `= new [T]{}`（废止 `=[]`，见 RFC-0005） |
| 无代码块 | 隐式私有后备字段 + 合成访问器 |
| 有代码块 | 不生成隐式后备；`set` 内隐式 `value` |
| accessor 可见性 | `set` 可 `private`/`protected`/`internal`；`get` 默认同属性 |
| `OnChange(fn)` | 仅纯自动 `get;`/`set;`；降糖为合成 set 末尾 `fn(value)`（单参） |
| 接口属性 | 仅契约：无体、无 `=`、无 OnChange |

## 3. 编译转换

1. 自动无体：字段槽 + `getX`/`setX`（既有）；初值写入构造/实例初始化路径。
2. 手写体：生成真实方法体；属性读写仍走成员访问语法。
3. `OnChange`：合成 set 在赋值后备字段后调用具名函数/方法。

## 4. 语义约束

- `val` 不得有 `set`。
- `var` 自动属性必须有 `set`（可带可见性）。
- 手写体与 `OnChange` 互斥。
- 静态自动属性本版仍可不做（若触达则报错，与现状一致或按实现放开——默认保持「不支持静态自动属性」）。

## 5. 示例

### 5.1 正例

```hao
class Box {
    var items: [Int] { get; set; } = new [Int]{};
    var n: Int { get; private set; } = 0;
}
```

```hao
// var xs: [Int] { get; set; } = [];
```

## 6. 歧义分析

| 写法 | 含义 |
|------|------|
| 字段 `var x: Int = 1;` | 不是属性 |
| `OnChange` | 属性后缀上下文关键字，不是通用关键字 |
| 完整事件系统 | 不做；仅单参回调降糖 |
