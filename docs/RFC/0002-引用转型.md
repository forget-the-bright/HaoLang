# RFC-0002：引用向上 / 向下转型

| 字段 | 值 |
|------|-----|
| 状态 | **Implemented** |
| 版本锚点 | OOP（`is` / `as`；赋值隐式向上） |
| 对标 | Java 引用转型；失败策略接近 Java（`as` panic），另提供 `is` 判定 |

## 1. 动机

在类/接口继承体系中切换**同一对象**的静态视图。必须与装箱严格区分：转型不分配新对象。

## 2. 语法规范

| 形态 | 写法 |
|------|------|
| 向上（隐式） | `var a: Animal = dog;` |
| 向下（显式） | `var d = a as Dog;`（失败 panic） |
| 判定 | `x is Dog` / `x is Map<?,?>` 等三形态（见 hao语法 OOP） |
| 非法 | 无继承关系的隐式赋值；用转型冒充装箱 |

## 3. 编译转换

- 向上：静态子类型检查通过即改类型视图；IR 通常同指针。
- 向下：`as` → 运行时类型检查（vtable / typeId）；失败 `hao_panic_cast` 类路径。
- `is` → 布尔判定，不抛。

门禁：`target/p9-smoke`（`oop_is_as_*`）。

## 4. 语义约束

- 向上安全、可隐式；向下必须显式。
- `as` 失败 → **运行时 panic**（非空安全 `as?`；本语言未提供 C# 式可空 `as`）。
- 与装箱正交：`Object o = 10` 是装箱+向上，不是「Int 变 Object 视图」。

## 5. 示例

### 5.1 正例

```hao
class Animal {}
class Dog : Animal {}

val d = new Dog();
val a: Animal = d;          // 向上
val back = a as Dog;        // 向下
fmt.println(a is Dog);
```

### 5.2 反例

```hao
val a: Animal = new Animal();
// val d = a as Dog;  // 运行时 panic
```

## 6. 歧义分析

| | 装箱（RFC-0001） | 引用转型（本 RFC） |
|--|-----------------|-------------------|
| 操作数 | 值类型 ↔ 包装 | 引用 ↔ 引用 |
| 堆对象 | 新建包装 | 同一对象 |
| 隐式 | 匹配对装箱 | 仅向上 |
| 显式失败 | 类型不符 panic | `as` 不符 panic |
