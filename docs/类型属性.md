## 1. 四属性定义（语言可见语义）

| 属性 | 含义 | GC / 赋值后果 |
|------|------|----------------|
| **IsValueType** | 复制即完整独立；语言值不是堆引用 | 栈/寄存器直接存载荷；赋值**不**走写屏障 |
| **IsReference** | 语言值是指向托管堆的指针；可配合 `T?` 表示 null | 局部须挂根；堆槽赋值须写屏障 |
| **GcManaged** | 指向的对象由 GC 分配/回收 | 根枚举必须覆盖；与 `isGcManaged` / 历史名 `isGcPointerType` 对齐 |
| **IsUnsafePointer** | 原生裸指针；**不**参与 GC | 禁止出 FFI 桥；仅桥内可见（理想态） |

### 1.1 组合规则（写死）

1. **IsValueType 与 IsReference 互斥**（语言分类层面）。  
2. **值类型 `T?`（如 `Int?`）**：语义仍是「可空值」，**不是**引用类型；实现上装箱为堆块 → **GcManaged=true**（`isBoxedNullable`）。  
3. **引用类型 `T?`（如 `String?`）**：IsReference ∧ GcManaged；null = 指针 0（零开销）。  
4. **`String` / `[T]` / `class` / `interface` / `Func`**：IsReference ∧ GcManaged。  
5. **IsUnsafePointer**：当前 `TypeKind` **无**对应一等类型；`isUnsafePointer()` 恒 `false`；见 §4 将就路径与 §8 路线 P3。

### 1.2 与编译器实现的对应（v0.55.58）

| 规范属性 | 代码落点 | 状态 |
|----------|----------|------|
| IsReference | `Type::isReferenceType()` | ✅ |
| IsValueType | `Type::isValueType()` | ✅ **一等 API**（数值/Bool/Char；含值类型 `T?`） |
| GcManaged | `Type::isGcManaged()`；`IRGen::isGcPointerType` → 委托前者 | ✅ **一等 API** |
| IsUnsafePointer | `Type::isUnsafePointer()` 恒 false | 🔸 API 占位；无 TypeKind |

## 3. 数组与 String 细则

### 3.1 `[T]`：对象是引用，元素跟 `T`

```text
语言值 arr: [T]  →  IsReference ∧ GcManaged（永远）
元素 T           →  再套用本表：
  · T 为值类型     →  数组 is_ptr=0，GC 不扫元素区
  · T 为引用/装箱可空 →  is_ptr=1，扫 [0..len) + 元素写屏障
```

对标 Java：`int[]` / `String[]` 的**数组对象都是引用**；差别只在元素。Hao `[Int]` / `[String]` 同构。

运行时：`hao_array_new(len, esz, is_ptr)`；IR 用 `isGcManaged(elem)`（经 `isGcPointerType`）。

### 3.2 `String`

| 项 | 口径 |
|----|------|
| 语言分类 | **引用类型**（不是值类型） |
| 表示 | `ptr` → 头 `{bytes→[Byte], cp_len}`；载荷 UTF-8，**cap≥len+1** 且 `data[len]=NUL`（FFI） |
| GC | 头 **`GC_KIND_SLOTS`**（bitmap bit0）；`[Byte]` 为 `GC_KIND_ARRAY` esz=1 |
| 长度 / 下标 | **Unicode 码点**（`.length` / `[i]` / `charAt`）；字节数用 `byteLength()` |
| 可变性 | 载荷对用户不可变；`getBytes()` **返回拷贝** |
| 包装 | `lang.String` 是 Class；内建 `String` 日常用 |

## 4. 隐式约定 → 一等属性（差距清单）

| 项 | v0.55.57 | v0.55.58 | 后续 |
|----|----------|----------|------|
| 四属性语言规范 | ✅ 本文 | ✅ | — |
| `Type` 一等 API | 仅 `isReferenceType`/`isBoxedNullable` | ✅ `isValueType`/`isGcManaged`/`isUnsafePointer` | 新代码优先 `isGcManaged` |
| `IsUnsafePointer` 类型/语法 | 无 | API 占位恒 false | 仍不对用户开放；资源走 NativeHandle |
| String/容器业务在 C | 大量 | 仍大量；§7 已盘点 | P2 分批上移 |
| FFI Handle | 无 | ✅ fs/net/regex | P3 ✅；P4 IO 业务上移 |

### 4.1 当前将就路径（点名，禁止新业务扩散）

- 用 **`UIntPtr`** 做「像指针」的算术（合法作指针宽整数；**不是**托管引用）。  
- ~~用 **`Long?` 藏资源/meta/原子胞**~~：**已清零**（v0.56.0）；合法 `Long?` 仅可空值 / tryRecv 出参 / invoke 位槽。  
- **`extern` 直接传 `ptr`** / C 字符串指针进入业务层而不拷贝成 `String`。  
- 以上**均不**构成正式 `IsUnsafePointer` 类型；资源与永生 meta 正式方案是 **NativeHandle**。

## 5. FFI 边界（语言侧承诺：**已执行** — 只拷贝 + 句柄）

对齐 [`方法论/FFI与运行时分层隔离.md`](方法论/FFI与运行时分层隔离.md) + [`方法论/HaoLang ABI 设计方法论 + 内存托管权责规范.md`](方法论/HaoLang%20ABI%20设计方法论%20+%20内存托管权责规范.md)：

| C 侧 | Hao 侧（**已执行**） |
|------|----------------|
| 数字 | 原生**值类型** |
| `char*` / C 字符串 | 入桥拷贝为 Hao `String`；出桥 libc 前 **`hao_ffi_dup_*`**（禁对外「借堆内 cstr」） |
| C 数组 / 字节 | 拷贝或填 Hao 自有缓冲（`hao_str_data` 仅桥内写本缓冲） |
| C 指针 / 资源（FILE*/socket/regex…） | **仅** `lang.NativeHandle`（代理释放一次；raw 属 C） |

**禁止第三种模式**：借 GC 堆内指针给 C 长期持有。`hao_str_cstr`/`data` = 桥私有（审计清单见 `runtime_internal.h`）。

## 7. 永久 C 底座（写死理由——不是延期）

> **禁止**「可后挪 / 评估中 / 示范旧路径共存」。能 Hao 的已上移并删 C；下表仅不可替代项。

| 留 C | 不可替代理由 |
|------|----------------|
| `hao_str_*` 布局原语（concat/len/char_at/alloc/from/get_bytes/byte_slice/byte_of_cp） | 串载荷布局+GC；**业务出口**已走 `@lang$String.concat` / `codePointLen` / `charAtCp`（P7b） |
| `atomicAdd` 等 `__atomic_*`（经 Handle 胞） | 无 Hao 原子 IR |
| reflect field get/set、invoke*、new_instance*；invoke 槽仍 `[Long]` 位型 | 裸槽 + thunk ABI；需 unsafe/IR；编组助手仅 `reflect` + Mvc/JSON/Html/channel |
| meta→String 的薄 `from_cstr(静态C串)` | 读编译器静态表 |
| `hao_fs_*` / getenv / system / remove / now_ns / offset | OS |
| `hao_fmt_double` / `hao_parse_double_cstr`（`runtime_float.c`） | 自研十进制；**禁** libc `strto*` / `%g`（P7c） |

### 7.1 已上移并删 C（P5 · v0.56.0）

| 符号/能力 | 落点 |
|-----------|------|
| `hao_str_substring` / `byte_index_of` / `char_to_str` | `lang.String` / `Character` |
| `hao_parse_{int,long,uint,ulong,bool}` + `*_to_str` | `Integer`/`Long`/`UInt`/`ULong`/`Boolean`；IR→`@lang$*.toStr` |
| `hao_time_field` / `hao_time_format` | `time.Time`（Hinnant civil） |
| `hao_hash_{int,long,bool,str}` / float C hash | `hash.Hash`（float 经 `fltBits`/`dblBits`；P7a 删 `runtime_hash.c`） |
| `hao_reflect_is_assignable` | `Class.isAssignableFrom` |
| `hao_sync_lock`/`unlock` | Mutex Hao CAS + safepoint |

### 7.1b P7（v0.57.0）

| 符号/能力 | 落点 |
|-----------|------|
| 标量 `hao_println_*` | `fmt`→`*.toStr` + `hao_println_str` |
| IR `+`/`.length`/`s[i]` 业务出口 | `@lang$String.concat` / `codePointLen` / `charAtCp` |
| float libc `strto*`/`%g` | `runtime_float.c` 自研；reflect field 同路径 |
| `thread` 句柄 `Long` | `NativeHandle`（drop=关 OS 句柄；join 显式 Wait） |
| soft-STW 热 miss | **v0.72 已删 HOT_GRACE**；`hao_gc_stw_grace_rescues` 恒 0 |

### 7.2 `runtime_array.c`

| 级别 | API | 理由 |
|------|-----|------|
| **永久 C 底座** | `hao_array_new` / `len` / `cap`(私有) / `check` / `get_obj` / **`hao_arraycopy`** / `clone` | 布局+GC；arraycopy≡System.arraycopy；**禁业务 `.hao` 直调布局** |

> 算法面（contains/indexOf/copyOf/fill/…）在 [`Arrays.hao`](../stdlib/src/collections/Arrays.hao) 与 `List`，组合内建 `[T]`。

### 8.1 IR 同步铁律（改 stdlib/ABI 必读）

改 **Handle 入参 / 已删 `hao_*` / toStr 落点** 时，**禁止只改 Hao/C**：

1. 搜 `src/irgen` 硬编码符号与合成路径（`TypeName.Class`、`toStringValue`、declare 表）。
2. 永生静态表（`@T.meta`、注解 `classMeta`）可继续存**裸** meta；**凡入 Hao `NativeHandle` API 必须经 `hao_handle_wrap` / `wrap_meta`**。
